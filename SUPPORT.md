# Support

Semver Weather is maintainer-supported open-source software with no service-level agreement.

1. Read the [README](README.md) and [troubleshooting guide](docs/TROUBLESHOOTING.md).
2. Reproduce with `fixtures/demo/manifest.json` or another synthetic/public input.
3. Search existing issues.
4. File the structured bug template with exact argv, cutoff, Node/npm versions, classification, and bounded sanitized logs.

Feature proposals should explain the reproducibility question and the smallest public or synthetic proof. Questions about private registries, production credentials, another package ecosystem, or running untrusted lifecycle scripts are outside the 0.1.x support boundary.

Use the [private advisory route](SECURITY.md) for vulnerabilities. Do not place secrets or private identifiers in any issue.
