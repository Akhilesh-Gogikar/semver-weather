# Social preview assets

- `social-preview.svg` is the editable, self-contained source.
- `social-preview.png` is the 1280 × 640 upload-ready GitHub social preview.
- README alt text: “Semver Weather social preview: dependency outcomes plotted across release history”

GitHub does not read this file from the repository automatically: a repository
admin uploads `social-preview.png` under **Settings → General → Social preview**
and checks the anonymous link preview on light and dark surfaces after each
change.

Keep the name, benefit, version, and repository URL synchronized with
`README.md`. Do not add adoption counts, external logos, partner names, or
trademarks without current evidence and explicit approval. Preserve the source
SVG when replacing the PNG so future contributors can update the asset without
a proprietary design file.
